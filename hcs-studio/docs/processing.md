# Processing modules

Generated by `scripts/gen_processing_docs.py` from the module definitions (`hcs-studio modules` prints the same reference).
Channel numbers start at 1. Modules marked **display only** must not be used for intensity measurement.

These algorithms are verified against synthetic images with a known answer. Validate them on your own data, and against your reference software, before relying on them for quantitative claims.

## Autofluorescence: AF channel subtraction (`af_channel`)

Subtracts `k × AF channel` from each target channel, then clips at 0. `k` is estimated by robust regression (Tukey biweight), which ignores pixels carrying real signal as long as background pixels are the majority.

Learns a plate-level estimate before processing; the estimate is recorded in `run_manifest.json`.

| Parameter | Default | Meaning |
|---|---|---|
| `channels` | None | Channel numbers to process, starting at 1. Empty = all channels. |
| `af_channel` | required | Number of the autofluorescence / empty channel. |
| `coefficients` | None | Manual bleed-through coefficient per channel number; empty = estimate. |
| `max_fields` | 20 | Fields sampled for the estimate. |
| `pixels_per_field` | 20000 | Pixels sampled per field. |

## Assay: apoptosis and cytotoxicity (`apoptosis`)

Assay (Phase 20c): apoptosis and cytotoxicity on the nuclei. An apoptosis marker (caspase-3/7, cleaved caspase-3, or annexin V measured on the cells) and a dead-cell dye (PI, SYTOX, DRAQ7) are thresholded from the vehicle nuclei (median + threshold_sd robust SD of log intensity; or a percentile; or Otsu over vehicle and positive controls); condensed nuclei (small and bright vs vehicle) or a classifier's classes count as apoptotic; very small bright objects are fragments, not cells. Categories viable / early / late apoptotic / necrotic, viable count, Z′ of the positive control, and GR from a time-zero count (0 h wells or time_zero_count): cytotoxic below 0, cytostatic below no_effect_gr. Writes `ap_` columns and `assays/apoptosis/`. See the Assays guide.

## Background removal (`background`)

Removes background per plane, typically after projection: top-hat, rolling ball or sliding paraboloid (estimated on a 3 × 3 mean), Gaussian or median background (subtracted or divided), a polynomial or spline surface fitted to background pixels, a constant (percentile or blank wells), or BaSiC-style flat- and dark-field estimated across the plate. Negatives are clipped; output stays linear. Each field reports the change inside objects and in the background, and warns when the radius is under 2× the typical object diameter.

Learns a plate-level estimate before processing; the estimate is recorded in `run_manifest.json`.

| Parameter | Default | Meaning |
|---|---|---|
| `channels` | None | Channel numbers to process, starting at 1. Empty = all channels. |
| `method` | 'tophat' | tophat: fast opening; rolling_ball / paraboloid: ImageJ-style; gaussian / median: large blur; polynomial / spline: surface fitted to background pixels; constant: percentile or blank wells; basic: flat- and dark-field from the plate. |
| `radius_um` | 25.0 | tophat, rolling_ball, paraboloid: radius; gaussian: sigma; median: window radius. Choose larger than the largest object (at least 2× its diameter). |
| `operation` | 'subtract' | gaussian, median, polynomial, spline: subtract the background, or divide by it (rescaled to its mean; corrects multiplicative shading). |
| `degree` | 2 | polynomial: degree of the surface. |
| `grid` | 8 | spline: number of control points along each side. |
| `constant_source` | 'percentile' | constant: a percentile of each field, or the mean of blank wells. |
| `percentile` | 5.0 | constant: percentile of each field. |
| `blank_wells` | [] | constant (blank_wells): wells without cells, e.g. [A01, P24]. Empty = wells marked 'blank' in the plate layout. |
| `darkfield` | True | basic: also estimate a dark-field. |
| `max_fields` | 100 | blank_wells, basic: fields sampled across the plate. |
| `object_diameter_um` | None | Typical object diameter for the radius check; empty = estimated from each field. |

## Assay: cell cycle (DNA content, EdU, pH3) (`cell_cycle`)

Assay (Phase 20a): cell cycle from the integrated nuclear intensity of a DNA stain, scaled so the vehicle wells' G1 peak is 2N; per well a Dean–Jett–Fox-style fit (Gaussian G1 and G2/M peaks with a shared CV, uniform broadened S phase) gives % G1, S and G2/M, with sub-G1 and > 4N by DNA content; optional EdU (2D gating) and pH3 (mitotic index), thresholds from the vehicle wells. Writes `cc_dna_n`, `cc_phase` per nucleus, the `cc_` readouts per well, and `assays/cell_cycle/` (calibration, per-well CSV, report). Warns about max projections and single confocal planes. ## Classify objects (`classify_objects`)

Applies an object classifier trained in the Classify panel (or with `hcs-studio train-classifier`) on example objects: random forest or histogram gradient boosting on the measured features. With `plate_robust_z` normalisation each plate's features become robust Z-scores of that plate first, which removes plate-to-plate intensity offsets but assumes most objects on a plate are alike. Writes the class, its probability and every class probability per object, and class counts and fractions per well; the classifier file's SHA-256, classes and cross-validated accuracy go into `tables/analysis_summary.json`.

Table step: runs on the object tables after all wells are processed, and can be applied to a finished run with `hcs-studio analyze`.

| Parameter | Default | Meaning |
|---|---|---|
| `object_type` | 'nuclei' | Objects to work on (a segmentation name). |
| `name` | 'class' | Objects get class_<name>, class_<name>_probability, class_<name>_p_<class>. |
| `model_path` | '' | Classifier file (.joblib) saved by HCS Studio. |
| `min_probability` | 0.0 | Objects whose best class is less likely than this are 'unassigned'. |

## Deconvolution (`deconvolution`)

Richardson-Lucy with total-variation regularisation (Dey et al. 2006) and Biggs-Andrews acceleration, or a one-step Wiener filter for quick previews. 3D for Z stacks (2D per plane with `force_2d`). The image is mirror-padded by the PSF half-size, a constant background is estimated (or given) and excluded from the result, and the result is non-negative. The PSF is computed from the metadata with `psfmodels` (vectorial or Gibson-Lanni; pinhole-aware for confocal) or loaded from a file saved by Tools → PSF tool, resampled to the image voxel size. Large images are split into overlapping Y/X tiles, blended linearly, whenever they would exceed the memory budget. Iterations, residual, runtime, tiles and the PSF used are recorded per channel in each well's `well_summary.json`. Runs on a CUDA GPU through PyTorch when one is available, otherwise on the CPU. **Validate against your reference software (e.g. Huygens) on bead and cell images before using it for quantitative claims** — see [validation.md](validation.md).

| Parameter | Default | Meaning |
|---|---|---|
| `channels` | None | Channel numbers to process, starting at 1. Empty = all channels. |
| `method` | 'rl' | rl: Richardson-Lucy with TV; wiener: fast, for quick previews. |
| `iterations` | 40 | Maximum RL iterations. |
| `tv_lambda` | 0.002 | Total-variation regularisation; 0 = off. |
| `accelerate` | True | Biggs-Andrews acceleration. |
| `stop_rel_change` | 0.0 | Stop when the relative change falls below this; 0 = off. |
| `background` | None | Constant background in counts; empty = estimate. |
| `wiener_nsr` | 0.01 | Wiener noise-to-signal ratio. |
| `psf_file` | None | Measured PSF file (from the PSF tool); empty = theoretical. |
| `psf_model` | 'vectorial' | Theoretical PSF model. |
| `sample_ri` | 1.33 | Sample refractive index. |
| `pinhole_au` | None | Confocal pinhole in Airy units; empty = from metadata. |
| `force_2d` | False | Deconvolve each Z plane separately. |
| `tile_size_px` | 0 | Process Y/X tiles of this size; 0 = automatic (tiles only when needed). |
| `max_memory_gb` | None | Memory one deconvolution may use; empty = half the free RAM (80% of free GPU memory). |
| `device` | 'auto' | Where to compute. |

## Assay: detect DNA-damage foci (`detect_foci`)

Assay (Phase 20b): DNA-damage foci inside nuclei. The threshold is calibrated on the vehicle wells (median + threshold_sd × robust SD of the response over the vehicle nuclei) unless fixed. With Z planes the detection is 3D. ## Flat-field correction (`flatfield`)

Estimates the illumination profile from many fields of the plate: each field is divided by its mean, the per-pixel median across fields removes the cells, and a smooth surface is fitted: a 2D polynomial (default, degree 4; accurate up to the image border) or a wide Gaussian (for illumination a polynomial cannot follow; it flattens the corners by a few percent). The median assumes most pixels are background: stains that cover much of each field (e.g. dense cytoplasm) bias the profile; where almost no background is left, the polynomial is not used and the channel falls back to smoothing (recorded as gaussian_fallback_channels in the manifest). The profile is normalised to mean 1, so the mean intensity of a field is preserved. This is a median-based estimate, not the BaSiC algorithm. It needs enough fields with varied content; it fails rather than guess when fewer than `min_fields` are available.

Learns a plate-level estimate before processing; the estimate is recorded in `run_manifest.json`.

| Parameter | Default | Meaning |
|---|---|---|
| `dark_offset` | 0.0 | Camera offset (counts) subtracted before correction. |
| `max_fields` | 200 | Maximum number of fields sampled across the plate. |
| `min_fields` | 8 | Fewer fields than this cannot separate shading from cells; the step fails. |
| `profile_fit` | 'polynomial' | Smooth surface fitted to the median: 2D polynomial, or Gaussian blur. |
| `polynomial_degree` | 4 | Degree of the 2D polynomial surface. |
| `smoothing_fraction` | 0.05 | Gaussian smoothing of the profile, as a fraction of the image width. |

## Object QC: outliers (`object_qc`)

Object-level QC: learns the median and robust spread (1.4826 × MAD) of size (log area), shape (solidity) and the mean intensity of the first channel (log) from objects sampled across the plate, and flags objects beyond the robust-Z threshold in any of them (merged cells, fragments, out-of-focus or debris-like objects). Writes `qc_outlier`, `qc_excluded` and `qc_reason` per object and the outlier count and fraction per well. Excluded objects are left out of per-well feature statistics and of later table steps; counts are unchanged. See the Image QC guide.

Table step: runs on the object tables after all wells are processed, and can be applied to a finished run with `hcs-studio analyze`.

## Pharmacology: dose–response and synergy (`pharmacology`)

Normalizes per-well readouts per plate and cell line (% of control, % inhibition or GR), checks plate QC (Z′, SSMD, CVs), fits dose–response curves (4PL/5PL/3PL in GraphPad Prism's form) and scores combination matrices (Bliss, HSA, Loewe, ZIP). Writes `pharmacology/` (tables, figures, HTML and PDF report) and adds curves and heat maps to `index.html`. Methods: docs/pharmacology.md.

Run step: runs once on the finished run (after all wells, the tables and the report); it does not change images, is not part of the pipeline hash, and can be applied to a finished run with `hcs-studio analyze`.

| Parameter | Default | Meaning |
|---|---|---|
| `readouts` | [] | Per-well readouts (columns of per_well_summary); empty = the first *_count readout. |
| `normalization` | 'percent_inhibition' | % of control, % inhibition (needs positive controls) or GR. |
| `models` | ['bliss', 'hsa', 'loewe', 'zip'] | Synergy models for combination matrices. |
| `curve_model` | '4pl' | Dose–response model. |
| `robust` | False | Robust (soft L1) curve fitting. |
| `outlier_mad` | None | Exclude wells beyond median ± k·MAD; empty = off. |
| `z_threshold` | 0.5 | Flag plates with Z′ below this. |
| `doubling_time_h` | None | GR: doubling time. |
| `assay_duration_h` | None | GR: assay duration. |
| `pdf` | True | Also write the PDF report. |

## Phenotypic clusters (`phenotypic_clusters`)

Groups objects by their features without labels: k-means, HDBSCAN, or Leiden (needs the optional `leidenalg` and `igraph`). Features are robust Z-scores clipped to ±10, optionally reduced by PCA. Clusters are learned on objects sampled across the plate; each object is then assigned (k-means: nearest centre; HDBSCAN and Leiden: majority of the 5 nearest sampled objects, an approximation). Cluster 1 is the largest, -1 is noise. Writes `cluster_<name>` per object and fractions per well; the features that set each cluster apart are listed in the analysis summary.

Table step: runs on the object tables after all wells are processed, and can be applied to a finished run with `hcs-studio analyze`.

| Parameter | Default | Meaning |
|---|---|---|
| `object_type` | 'nuclei' | Objects to work on (a segmentation name). |
| `name` | 'pheno' | Objects get cluster_<name>. |
| `features` | None | Features to cluster on; empty = all measured features. |
| `method` | 'kmeans' | Leiden needs the optional leidenalg and igraph packages. |
| `n_clusters` | 5 | k-means: number of clusters. |
| `min_cluster_size` | 50 | HDBSCAN: smallest cluster. |
| `resolution` | 1.0 | Leiden: higher = more clusters. |
| `n_neighbors` | 15 | Leiden: k-NN graph size. |
| `pca_components` | 0 | Reduce to this many principal components; 0 = off. |
| `max_fit_objects` | 50000 | Objects sampled across the plate to learn from. |
| `seed` | 0 | Random seed (sampling, k-means, Leiden). |

## Z projection (`projection`)

Collapses Z: maximum (default), mean, sum, minimum, standard deviation or extended depth of field (`variance`: sharpest plane per pixel; `pyramid`: multi-scale fusion). Planes: all, a range, or `auto` (the planes around the best focus by normalized variance or Brenner, per channel or from `focus_channel`). The planes used are recorded per field in `well_summary.json`.

| Parameter | Default | Meaning |
|---|---|---|
| `method` | 'max' | max (default), mean, sum, min, std (standard deviation), or edf = extended depth of field (in-focus detail of every plane). |
| `edf_method` | 'variance' | edf: variance = sharpest plane per pixel (local variance); pyramid = multi-scale (Laplacian pyramid, wavelet-like) fusion, smoother at plane boundaries. |
| `planes` | 'all' | all planes; a range (first/last plane); or auto = the planes around the best focus. |
| `first_plane` | 1 | range: first plane (from 1). |
| `last_plane` | None | range: last plane (empty = the last one). |
| `focus_metric` | 'normalized_variance' | auto: focus score of each plane (normalized variance or Brenner gradient). |
| `n_planes` | 5 | auto: number of planes kept around the best focus. |
| `focus_channel` | None | auto: channel whose focus chooses the planes for all channels; empty = each channel chooses its own planes. |

After the run, fields are flagged as out of focus or saturated relative to the plate, wells with low counts are flagged, and counts and densities per well leave out the excluded fields. Writes `tables/qc_flags.csv`.

| `saturation_fraction` | 0.001 | Saturated when more pixels than this are at maximum. |
| `low_count_fraction` | 0.3 | Low-count well when below this × plate median count. |

## Spatial clusters (`spatial_clusters`)

Spatial organisation of objects in the whole well (needs `stitch_well`) or in each field: colonies by DBSCAN or HDBSCAN, nearest-neighbour distances, the Clark-Evans ratio (Donnelly edge correction), Voronoi cell area and Delaunay neighbours (NaN where the cell is not closed inside the imaged area), Ripley's K, L and H = L − r with border correction, and the pair correlation g(r), compared with envelopes from simulated complete spatial randomness in the same area. `spatial_pattern_<r>um` is +1 (clustered), -1 (regular) or 0 (consistent with randomness at the 5 % pointwise level with 39 simulations). Full curves per well are in `wells/<W>/analysis.json`.

Table step: runs on the object tables after all wells are processed, and can be applied to a finished run with `hcs-studio analyze`.

| Parameter | Default | Meaning |
|---|---|---|
| `object_type` | 'nuclei' | Objects to work on (a segmentation name). |
| `scope` | 'well' | Whole well (needs the Stitch well step) or each field separately. |
| `method` | 'dbscan' | Colony detection method. |
| `eps_um` | 20.0 | DBSCAN: objects closer than this join a colony. |
| `min_samples` | 5 | DBSCAN: neighbours to start a colony. |
| `min_cluster_size` | 10 | HDBSCAN: smallest colony. |
| `radii_um` | [10.0, 25.0, 50.0, 100.0] | Radii for Ripley's H and g in the summary. |
| `simulations` | 39 | CSR simulations for the envelopes; 0 = none. |
| `seed` | 0 | Random seed for the simulations. |

## Stitch well (`stitch_well`)

Places the fields of each well in one coordinate system from their stage positions. When fields overlap, the way stage axes map to image axes is found from the overlaps (or set), and positions are refined by phase correlation of each overlap (sub-pixel, Hanning-windowed) and solved together by least squares; overlaps that correlate poorly or would move a field by more than `max_correction_fraction` are ignored. Objects get `well_x_um`, `well_y_um` and `in_overlap_duplicate` (the copy seen in a field whose centre is farther away), so each object is counted once; well counts and densities use the area the fields cover together. Writes `previews/mosaic.png` and the field positions to `well_summary.json`. Images are not resampled or fused.

| Parameter | Default | Meaning |
|---|---|---|
| `channel` | 1 | Channel used to register overlaps. |
| `refine` | True | Refine stage positions by phase correlation of the overlaps. |
| `stage_orientation` | 'auto' | How stage axes map to the image: auto (from the overlaps), or x right, y down, x right, y up, x left, y down, x left, y up |
| `max_correction_fraction` | 0.1 | Largest accepted correction, × the field size. |
| `min_correlation` | 0.3 | Overlaps that correlate less are not used. |
| `image_max_size` | 1024 | Fields are downsampled to this for matching. |
| `save_mosaic` | False | Also write the well as one linear image (mosaic.ome.tif, all channels; overlaps averaged), e.g. of projected and background-corrected fields. |
| `mosaic_downsample` | 2 | Mosaic image: block-average by this factor (1 = full resolution; needs all fields of a well in memory). |

## Assay: nuclear translocation (`translocation`)

Assay (Phase 20d): nuclear/cytoplasmic ratio of a reporter per cell (nucleus vs the cytoplasm label set), log2 ratio, and responding cells above a threshold from the unstimulated controls (median + threshold_sd robust SD of log N/C; a percentile; Otsu over unstimulated and stimulated cells; or fixed). mode agonist: vehicle = unstimulated; inhibitor: positive controls = unstimulated. Per well % responding, median N/C, activation between the controls, Z′. Writes `tl_` columns and `assays/translocation/`. EC50/IC50 with the pharmacology step on tl_responding_pct. See the Assays guide.

Table step: runs on the object tables after all wells are processed, and can be applied to a finished run with `hcs-studio analyze`.
