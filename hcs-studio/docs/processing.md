# Processing modules

Generated by `scripts/gen_processing_docs.py` from the module definitions (`hcs-studio modules` prints the same reference).
Channel numbers start at 1. Modules marked **display only** must not be used for intensity measurement.

These algorithms are verified against synthetic images with a known answer. Validate them on your own data, and against your reference software, before relying on them for quantitative claims.

## Autofluorescence: AF channel subtraction (`af_channel`)

Subtracts `k × AF channel` from each target channel, then clips at 0. `k` is estimated by robust regression (Tukey biweight), which ignores pixels carrying real signal as long as background pixels are the majority.

Learns a plate-level estimate before processing; the estimate is recorded in `run_manifest.json`.

| Parameter | Default | Meaning |
|---|---|---|
| `channels` | None | Channel numbers to process, starting at 1. Empty = all channels. |
| `af_channel` | required | Number of the autofluorescence / empty channel. |
| `coefficients` | None | Manual bleed-through coefficient per channel number; empty = estimate. |
| `max_fields` | 20 | Fields sampled for the estimate. |
| `pixels_per_field` | 20000 | Pixels sampled per field. |

## Autofluorescence: reference wells (`af_reference`)

| Parameter | Default | Meaning |

| `max_fields` | 50 | Maximum reference fields sampled. |
| `smoothing_fraction` | 0.02 | Smoothing of the AF image (fraction of width). |

## Classify objects (`classify_objects`)

Applies an object classifier trained in the Classify panel (or with `hcs-studio train-classifier`) on example objects: random forest or histogram gradient boosting on the measured features. With `plate_robust_z` normalisation each plate's features become robust Z-scores of that plate first, which removes plate-to-plate intensity offsets but assumes most objects on a plate are alike. Writes the class, its probability and every class probability per object, and class counts and fractions per well; the classifier file's SHA-256, classes and cross-validated accuracy go into `tables/analysis_summary.json`.

Table step: runs on the object tables after all wells are processed, and can be applied to a finished run with `hcs-studio analyze`.

| Parameter | Default | Meaning |
|---|---|---|
| `object_type` | 'nuclei' | Objects to work on (a segmentation name). |
| `name` | 'class' | Objects get class_<name>, class_<name>_probability, class_<name>_p_<class>. |
| `model_path` | '' | Classifier file (.joblib) saved by HCS Studio. |
| `min_probability` | 0.0 | Objects whose best class is less likely than this are 'unassigned'. |

## Measure: colocalization (`colocalization`)

Warns about saturated pixels and chromatic shift. Optional object-based colocalization: the fraction of objects in one label set near objects of another. Writes `coloc.csv` per well.

| `costes_below` | 'and' | Costes: pixels below both thresholds ('and') or either ('or'). |

| `object_labels_a` | None | Object-based: fraction of these objects (e.g. spots) near ... |
| `object_labels_b` | None | ... these objects. |

## Deconvolution (`deconvolution`)

Richardson-Lucy with total-variation regularisation (Dey et al. 2006) and Biggs-Andrews acceleration, or a one-step Wiener filter for quick previews. 3D for Z stacks (2D per plane with `force_2d`). The image is mirror-padded by the PSF half-size, a constant background is estimated (or given) and excluded from the result, and the result is non-negative. The PSF is computed from the metadata with `psfmodels` (vectorial or Gibson-Lanni; pinhole-aware for confocal) or loaded from a file saved by Tools → PSF tool, resampled to the image voxel size. Large images are split into overlapping Y/X tiles, blended linearly, whenever they would exceed the memory budget. Iterations, residual, runtime, tiles and the PSF used are recorded per channel in each well's `well_summary.json`. Runs on a CUDA GPU through PyTorch when one is available, otherwise on the CPU. **Validate against your reference software (e.g. Huygens) on bead and cell images before using it for quantitative claims** — see [validation.md](validation.md).

| Parameter | Default | Meaning |
|---|---|---|
| `channels` | None | Channel numbers to process, starting at 1. Empty = all channels. |
| `method` | 'rl' | rl: Richardson-Lucy with TV; wiener: fast, for quick previews. |
| `iterations` | 40 | Maximum RL iterations. |
| `tv_lambda` | 0.002 | Total-variation regularisation; 0 = off. |
| `accelerate` | True | Biggs-Andrews acceleration. |
| `stop_rel_change` | 0.0 | Stop when the relative change falls below this; 0 = off. |
| `background` | None | Constant background in counts; empty = estimate. |
| `wiener_nsr` | 0.01 | Wiener noise-to-signal ratio. |
| `psf_file` | None | Measured PSF file (from the PSF tool); empty = theoretical. |
| `psf_model` | 'vectorial' | Theoretical PSF model. |
| `sample_ri` | 1.33 | Sample refractive index. |
| `pinhole_au` | None | Confocal pinhole in Airy units; empty = from metadata. |
| `force_2d` | False | Deconvolve each Z plane separately. |
| `tile_size_px` | 0 | Process Y/X tiles of this size; 0 = automatic (tiles only when needed). |
| `max_memory_gb` | None | Memory one deconvolution may use; empty = half the free RAM (80% of free GPU memory). |
| `device` | 'auto' | Where to compute. |

## Spot detection (LoG / DoG) (`detect_spots`)

Finds sub-cellular spots with a Laplacian-of-Gaussian or difference-of-Gaussians filter tuned to the spot size, thresholded at a multiple of the robust noise level. Each spot is linked to the cell under its centre; spots outside cells are dropped unless `only_inside_parent` is off.

| Parameter | Default | Meaning |
|---|---|---|
| `channel` | required | Channel with the spots. |
| `output` | 'spots' | Name of the new label set. |
| `parent` | 'cells' | Label set the spots belong to; empty = none. |
| `diameter_um` | 0.6 | Typical spot diameter in µm. |
| `method` | 'log' | Laplacian or difference of Gaussians. |
| `threshold_sd` | 5.0 | Detection threshold in robust noise SDs of the filtered image. |
| `only_inside_parent` | True | Drop spots outside any parent object. |

## Flat-field correction (`flatfield`)

Estimates the illumination profile from many fields of the plate: each field is divided by its mean, the per-pixel median across fields removes the cells, and a smooth surface is fitted: a 2D polynomial (default, degree 4; accurate up to the image border) or a wide Gaussian (for illumination a polynomial cannot follow; it flattens the corners by a few percent). The median assumes most pixels are background: stains that cover much of each field (e.g. dense cytoplasm) bias the profile; where almost no background is left, the polynomial is not used and the channel falls back to smoothing (recorded as gaussian_fallback_channels in the manifest). The profile is normalised to mean 1, so the mean intensity of a field is preserved. This is a median-based estimate, not the BaSiC algorithm. It needs enough fields with varied content; it fails rather than guess when fewer than `min_fields` are available.

Learns a plate-level estimate before processing; the estimate is recorded in `run_manifest.json`.

| Parameter | Default | Meaning |
|---|---|---|
| `dark_offset` | 0.0 | Camera offset (counts) subtracted before correction. |
| `max_fields` | 200 | Maximum number of fields sampled across the plate. |
| `min_fields` | 8 | Fewer fields than this cannot separate shading from cells; the step fails. |
| `profile_fit` | 'polynomial' | Smooth surface fitted to the median: 2D polynomial, or Gaussian blur. |
| `polynomial_degree` | 4 | Degree of the 2D polynomial surface. |
| `smoothing_fraction` | 0.05 | Gaussian smoothing of the profile, as a fraction of the image width. |

## Phenotypic clusters (`phenotypic_clusters`)

Groups objects by their features without labels: k-means, HDBSCAN, or Leiden (needs the optional `leidenalg` and `igraph`). Features are robust Z-scores clipped to ±10, optionally reduced by PCA. Clusters are learned on objects sampled across the plate; each object is then assigned (k-means: nearest centre; HDBSCAN and Leiden: majority of the 5 nearest sampled objects, an approximation). Cluster 1 is the largest, -1 is noise. Writes `cluster_<name>` per object and fractions per well; the features that set each cluster apart are listed in the analysis summary.

Table step: runs on the object tables after all wells are processed, and can be applied to a finished run with `hcs-studio analyze`.

| Parameter | Default | Meaning |
|---|---|---|
| `object_type` | 'nuclei' | Objects to work on (a segmentation name). |
| `name` | 'pheno' | Objects get cluster_<name>. |
| `features` | None | Features to cluster on; empty = all measured features. |
| `method` | 'kmeans' | Leiden needs the optional leidenalg and igraph packages. |
| `n_clusters` | 5 | k-means: number of clusters. |
| `min_cluster_size` | 50 | HDBSCAN: smallest cluster. |
| `resolution` | 1.0 | Leiden: higher = more clusters. |
| `n_neighbors` | 15 | Leiden: k-NN graph size. |
| `pca_components` | 0 | Reduce to this many principal components; 0 = off. |
| `max_fit_objects` | 50000 | Objects sampled across the plate to learn from. |
| `seed` | 0 | Random seed (sampling, k-means, Leiden). |

## Spatial clusters (`spatial_clusters`)

Spatial organisation of objects in the whole well (needs `stitch_well`) or in each field: colonies by DBSCAN or HDBSCAN, nearest-neighbour distances, the Clark-Evans ratio (Donnelly edge correction), Voronoi cell area and Delaunay neighbours (NaN where the cell is not closed inside the imaged area), Ripley's K, L and H = L − r with border correction, and the pair correlation g(r), compared with envelopes from simulated complete spatial randomness in the same area. `spatial_pattern_<r>um` is +1 (clustered), -1 (regular) or 0 (consistent with randomness at the 5 % pointwise level with 39 simulations). ## Stitch well (`stitch_well`)

Places the fields of each well in one coordinate system from their stage positions. When fields overlap, the way stage axes map to image axes is found from the overlaps (or set), and positions are refined by phase correlation of each overlap (sub-pixel, Hanning-windowed) and solved together by least squares; overlaps that correlate poorly or would move a field by more than `max_correction_fraction` are ignored. Objects get `well_x_um`, `well_y_um` and `in_overlap_duplicate` (the copy seen in a field whose centre is farther away), so each object is counted once; well counts and densities use the area the fields cover together. Writes `previews/mosaic.png` and the field positions to `well_summary.json`. Images are not resampled or fused.

| Parameter | Default | Meaning |
|---|---|---|
| `channel` | 1 | Channel used to register overlaps. |
| `refine` | True | Refine stage positions by phase correlation of the overlaps. |
| `stage_orientation` | 'auto' | How stage axes map to the image: auto (from the overlaps), or x right, y down, x right, y up, x left, y down, x left, y up |
| `max_correction_fraction` | 0.1 | Largest accepted correction, × the field size. |
| `min_correlation` | 0.3 | Overlaps that correlate less are not used. |
| `image_max_size` | 1024 | Fields are downsampled to this for matching. |
