# Processing modules

Generated by `scripts/gen_processing_docs.py` from the module definitions (`hcs-studio modules` prints the same reference).
Channel numbers start at 1. Modules marked **display only** must not be used for intensity measurement.

These algorithms are verified against synthetic images with a known answer. Validate them on your own data, and against your reference software, before relying on them for quantitative claims.

## Autofluorescence: AF channel subtraction (`af_channel`)

Subtracts `k × AF channel` from each target channel, then clips at 0. `k` is estimated by robust regression (Tukey biweight), which ignores pixels carrying real signal as long as background pixels are the majority.

Learns a plate-level estimate before processing; the estimate is recorded in `run_manifest.json`.

| Parameter | Default | Meaning |
|---|---|---|
| `channels` | None | Channel numbers to process, starting at 1. Empty = all channels. |
| `af_channel` | required | Number of the autofluorescence / empty channel. |
| `coefficients` | None | Manual bleed-through coefficient per channel number; empty = estimate. |
| `max_fields` | 20 | Fields sampled for the estimate. |
| `pixels_per_field` | 20000 | Pixels sampled per field. |

## Autofluorescence: reference wells (`af_reference`)

Subtracts the autofluorescence measured in unstained or vehicle-only wells, then clips at 0. Place it after flat-field correction.

Learns a plate-level estimate before processing; the estimate is recorded in `run_manifest.json`.

| Parameter | Default | Meaning |
|---|---|---|
| `channels` | None | Channel numbers to process, starting at 1. Empty = all channels. |
| `reference_wells` | [] | Unstained / vehicle-only wells, e.g. [A01, A02]. Empty = wells marked 'unstained' in the plate layout. |
| `mode` | 'scalar' | scalar: one value per channel; image: smooth per-pixel AF profile. |
| `max_fields` | 50 | Maximum reference fields sampled. |
| `smoothing_fraction` | 0.02 | Smoothing of the AF image (fraction of width). |

## Background subtraction (`background`)

Removes smooth background per plane. The radius must be larger than the largest object, or object intensity is removed too.

| Parameter | Default | Meaning |
|---|---|---|
| `channels` | None | Channel numbers to process, starting at 1. Empty = all channels. |
| `method` | 'tophat' | tophat: fast morphological opening; rolling_ball: slower, smoother. |
| `radius_um` | 25.0 | Radius in µm; choose larger than the largest object. |

## Clarity preset (`clarity`) — **display only**

Mild Gaussian denoise, then an unsharp mask that does not amplify detail at the noise level (limits ringing and noise after deconvolution), then CLAHE.

| Parameter | Default | Meaning |
|---|---|---|
| `channels` | None | Channel numbers to process, starting at 1. Empty = all channels. |
| `amount` | 0.8 | Strength of detail enhancement. |
| `denoise_sigma_px` | 0.7 | Mild pre-smoothing (pixels). |
| `detail_sigma_px` | 3.0 | Scale of enhanced detail. |
| `noise_gate` | 3.0 | Detail weaker than this many noise SDs is not amplified (limits ringing). |
| `tile_um` | 60.0 | CLAHE tile size in µm. |
| `clip_limit` | 0.005 | CLAHE contrast limit. |

## Measure: colocalization (`colocalization`)

Pearson, Spearman, Li's ICQ, Manders M1/M2, thresholded tM1/tM2 with Costes automatic thresholds (or manual ones), overlap coefficients and, optionally, the Costes randomization p-value, per object or for the whole field, after background subtraction. Warns about saturated pixels and chromatic shift. Optional object-based colocalization: the fraction of objects in one label set near objects of another. Writes `coloc.csv` per well.

| Parameter | Default | Meaning |
|---|---|---|
| `channel_a` | required | First channel. |
| `channel_b` | required | Second channel. |
| `scope` | 'objects' | objects: each object of 'labels'; field: all of them together. |
| `labels` | 'cells' | Label set giving the objects or the mask; empty = whole field. |
| `background` | 'outside_objects' | Subtracted before Manders: median outside objects, 1st percentile, or none. |
| `thresholds` | None | Manual thresholds [A, B] after background subtraction; empty = Costes. |
| `costes_below` | 'and' | Costes: pixels below both thresholds ('and') or either ('or'). |
| `randomizations` | 0 | Costes randomization test; 0 = off. |
| `block_size_um` | None | Scramble block size; empty = lateral PSF FWHM from the metadata. |
| `saturation_warning_fraction` | 0.001 | Warn when more raw pixels than this are saturated. |
| `object_labels_a` | None | Object-based: fraction of these objects (e.g. spots) near ... |
| `object_labels_b` | None | ... these objects. |
| `object_distance_um` | 0.0 | Object-based: 0 = overlapping. |

Rescales each channel to 0-1 between two percentiles and applies gamma.

| Parameter | Default | Meaning |
|---|---|---|
| `channels` | None | Channel numbers to process, starting at 1. Empty = all channels. |
| `low_percentile` | 0.1 | Maps to black. |
| `high_percentile` | 99.9 | Maps to white. |

## Deconvolution (`deconvolution`)

Richardson-Lucy with total-variation regularisation (Dey et al. 2006) and Biggs-Andrews acceleration, or a one-step Wiener filter for quick previews. 3D for Z stacks (2D per plane with `force_2d`). The image is mirror-padded by the PSF half-size, a constant background is estimated (or given) and excluded from the result, and the result is non-negative. The PSF is computed from the metadata with `psfmodels` (vectorial or Gibson-Lanni; pinhole-aware for confocal) or loaded from a file saved by Tools → PSF tool, resampled to the image voxel size. Large images are split into overlapping Y/X tiles, blended linearly, whenever they would exceed the memory budget. Iterations, residual, runtime, tiles and the PSF used are recorded per channel in each well's `well_summary.json`. Runs on a CUDA GPU through PyTorch when one is available, otherwise on the CPU. **Validate against your reference software (e.g. Huygens) on bead and cell images before using it for quantitative claims** — see [validation.md](validation.md).

| Parameter | Default | Meaning |
|---|---|---|
| `channels` | None | Channel numbers to process, starting at 1. Empty = all channels. |
| `method` | 'rl' | rl: Richardson-Lucy with TV; wiener: fast, for quick previews. |
| `iterations` | 40 | Maximum RL iterations. |
| `tv_lambda` | 0.002 | Total-variation regularisation; 0 = off. |
| `accelerate` | True | Biggs-Andrews acceleration. |
| `stop_rel_change` | 0.0 | Stop when the relative change falls below this; 0 = off. |
| `background` | None | Constant background in counts; empty = estimate. |
| `wiener_nsr` | 0.01 | Wiener noise-to-signal ratio. |
| `psf_file` | None | Measured PSF file (from the PSF tool); empty = theoretical. |
| `psf_model` | 'vectorial' | Theoretical PSF model. |
| `sample_ri` | 1.33 | Sample refractive index. |
| `pinhole_au` | None | Confocal pinhole in Airy units; empty = from metadata. |
| `force_2d` | False | Deconvolve each Z plane separately. |
| `tile_size_px` | 0 | Process Y/X tiles of this size; 0 = automatic (tiles only when needed). |
| `max_memory_gb` | None | Memory one deconvolution may use; empty = half the free RAM (80% of free GPU memory). |
| `device` | 'auto' | Where to compute. |

## Denoise (`denoise`)

Smoothing filters. Output is still treated as measurement-grade, but median and non-local means are not strictly linear; prefer Gaussian or none for quantitative work.

| Parameter | Default | Meaning |
|---|---|---|
| `channels` | None | Channel numbers to process, starting at 1. Empty = all channels. |
| `method` | 'gaussian' | nlm = non-local means (slow, preserves edges). |
| `sigma_px` | 1.0 | Gaussian sigma in pixels. |
| `median_size_px` | 3 | Median window in pixels (odd). |
| `nlm_strength` | 1.0 | Non-local means strength, in units of the noise level. |

## Spot detection (LoG / DoG) (`detect_spots`)

Finds sub-cellular spots with a Laplacian-of-Gaussian or difference-of-Gaussians filter tuned to the spot size, thresholded at a multiple of the robust noise level. Each spot is linked to the cell under its centre; spots outside cells are dropped unless `only_inside_parent` is off.

| Parameter | Default | Meaning |
|---|---|---|
| `channel` | required | Channel with the spots. |
| `output` | 'spots' | Name of the new label set. |
| `parent` | 'cells' | Label set the spots belong to; empty = none. |
| `diameter_um` | 0.6 | Typical spot diameter in µm. |
| `method` | 'log' | Laplacian or difference of Gaussians. |
| `threshold_sd` | 5.0 | Detection threshold in robust noise SDs of the filtered image. |
| `only_inside_parent` | True | Drop spots outside any parent object. |

## Cells from nuclei (expansion) (`expand_cells`)

Grows each nucleus outward by up to `distance_um`, without overlap, so each cell keeps its nucleus' ID (cell 7 contains nucleus 7). Optionally limited to pixels where a cytoplasm channel is above a threshold.

| Parameter | Default | Meaning |
|---|---|---|
| `nuclei` | 'nuclei' | Label set to grow from. |
| `output` | 'cells' | Name of the new label set. |
| `distance_um` | 5.0 | Maximum growth in µm. |
| `mask_channel` | None | Limit growth to pixels where this channel is bright. |
| `mask_threshold` | None | Threshold for mask_channel; empty = Otsu. |

## Filter objects (`filter_objects`)

Removes objects touching the border, outside a size range, below a solidity, or outside an intensity range (intensity gates need linear data, so put the filter before display-only steps). Objects of child label sets lose their parent or are removed with it. Removed IDs are not renumbered.

| Parameter | Default | Meaning |
|---|---|---|
| `labels` | 'nuclei' | Label set to filter. |
| `remove_edge` | True | Remove objects touching the image border. |
| `min_size` | None | Minimum area (µm², µm³ in 3D). |
| `max_size` | None | Maximum area (µm², µm³ in 3D). |
| `min_solidity` | None | 2D only: area / convex area. |
| `intensity_channel` | None | Channel for the intensity gate. |
| `min_mean_intensity` | None | Keep objects at least this bright. |
| `max_mean_intensity` | None | Keep objects at most this bright. |
| `remove_children` | True | Also remove objects of child label sets whose parent is removed. |

## Flat-field correction (`flatfield`)

Estimates the illumination profile from many fields of the plate: each field is divided by its mean, the per-pixel median across fields removes the cells, and a wide Gaussian keeps the smooth shading. The profile is normalised to mean 1, so the mean intensity of a field is preserved. This is a median-based estimate, not the BaSiC algorithm. It needs enough fields with varied content; it fails rather than guess when fewer than `min_fields` are available.

Learns a plate-level estimate before processing; the estimate is recorded in `run_manifest.json`.

| Parameter | Default | Meaning |
|---|---|---|
| `dark_offset` | 0.0 | Camera offset (counts) subtracted before correction. |
| `max_fields` | 200 | Maximum number of fields sampled across the plate. |
| `min_fields` | 8 | Fewer fields than this cannot separate shading from cells; the step fails. |
| `smoothing_fraction` | 0.05 | Gaussian smoothing of the profile, as a fraction of the image width. |

## Measure: objects (`measure_objects`)

Measures every object of the chosen label sets on the linear image (never on contrast/CLAHE/clarity output): morphology in µm, intensity per channel, radial distribution, Haralick texture, granularity, optional Zernike moments, counts of child objects (e.g. spots per cell), nuclear/cytoplasmic ratios and neighbours. Writes `objects.parquet` per well. Column reference: [measurements.md](measurements.md).

| Parameter | Default | Meaning |
|---|---|---|
| `labels` | None | Label sets to measure; empty = all. |
| `channels` | None | Channels to measure; empty = all. |
| `percentiles` | [5, 25, 75, 95] | Intensity percentiles. |
| `radial_bins` | 3 | Rings from edge to centre. |
| `texture` | True | Haralick texture features. |
| `texture_scales_px` | [1, 3] | Haralick pixel distances. |
| `granularity` | True | Granularity spectrum. |
| `granularity_max_radius_px` | 6 | Largest opening radius. |
| `zernike` | False | Zernike shape moments (2D). |
| `neighbor_radius_um` | 20.0 | Radius for neighbour counts. |
| `nucleus_labels` | 'nuclei' | Label set used for nuclear/cytoplasmic ratios of its children. |

## Measure: field QC and counts (`qc`)

Per field: focus score (normalised variance of the Laplacian), fraction of saturated pixels, imaged area and object counts. After the run, fields are flagged as out of focus or saturated relative to the plate, wells with low counts are flagged, and counts and densities per well leave out the excluded fields. Writes `tables/qc_flags.csv`.

| Parameter | Default | Meaning |
|---|---|---|
| `focus_channel` | 1 | Channel used for the focus score. |
| `focus_fraction` | 0.5 | Out of focus when the score is below this × plate median. |
| `saturation_fraction` | 0.001 | Saturated when more pixels than this are at maximum. |
| `low_count_fraction` | 0.3 | Low-count well when below this × plate median count. |
| `count_labels` | None | Label set for counts; empty = first. |
| `exclude_out_of_focus` | True | Leave out-of-focus fields out of counts. |
| `exclude_edge_fields` | False | Leave fields at the edge of the well out of counts (needs ≥ 9 fields). |

## Register channels (chromatic shift) (`register_channels`)

Corrects chromatic shift by translating channels, either by given shifts in µm or by shifts measured on an image of multicolour beads. Linear (sub-pixel interpolation), so measurements stay valid. Place it before segmentation and colocalization.

Learns a plate-level estimate before processing; the estimate is recorded in `run_manifest.json`.

| Parameter | Default | Meaning |
|---|---|---|
| `shifts_um` | {} | Per channel number: [dy, dx] (or [dz, dy, dx]) in µm to apply. |
| `reference_channel` | 1 | Channel the others are aligned to. |
| `bead_image` | None | Image of multicolour beads to estimate the shifts from (overrides shifts_um). |

## Segmentation: Cellpose (`segment_cellpose`)

Cellpose 4 (`cpsam_v2` is the default Cellpose-SAM model). Give one channel, or two (e.g. cytoplasm plus nuclei) for whole cells. The diameter is optional. Z stacks are segmented in 3D (`do_3d`), plane by plane with stitching, or plane by plane. A trained model file can be used in place of a built-in name. Uses the GPU when available; on the CPU expect about 15 s per 512 × 512 field.

| Parameter | Default | Meaning |
|---|---|---|
| `channel` | required | Channel to segment (nuclear stain, or cytoplasm/membrane). |
| `second_channel` | None | Optional extra channel (e.g. nuclei when segmenting cells). |
| `output` | 'nuclei' | Name of the new label set. |
| `model` | 'cpsam_v2' | cpsam_v2, cpsam, cpdino, cpdino-vitb, or a trained model file. |
| `diameter_um` | None | Typical object diameter in µm; empty = let the model decide. |
| `flow_threshold` | 0.4 | Higher = more (less certain) objects. |
| `cellprob_threshold` | 0.0 | Lower = larger objects. |
| `min_size_px` | 15 | Remove objects smaller than this. |
| `do_3d` | False | Segment Z stacks in 3D (else plane by plane). |
| `stitch_threshold` | 0.0 | 2D mode on stacks: stitch planes above this overlap. |
| `parent` | None | Link each object to the object it overlaps most in this label set. |
| `batch_size` | 8 | Tiles per GPU batch. |
| `device` | 'auto' | auto, cpu or gpu. |

## Segmentation: threshold + watershed (`segment_classical`)

Smooths the channel, thresholds it (Otsu, Li or triangle; `local` subtracts a smooth background first, for uneven illumination), fills holes and separates touching objects by watershed on the distance transform. Fast and transparent; best for well-separated, evenly stained nuclei and as a fallback when no model is available.

| Parameter | Default | Meaning |
|---|---|---|
| `channel` | required | Channel to segment (e.g. the nuclear stain). |
| `output` | 'nuclei' | Name of the new label set. |
| `method` | 'otsu' | Threshold method; local adapts to uneven background. |
| `local_block_um` | 50.0 | Neighbourhood for 'local', in µm. |
| `offset` | 0.0 | Added to the threshold (intensity units). |
| `smoothing_um` | 1.0 | Gaussian smoothing before thresholding. |
| `split_touching` | True | Separate touching objects by watershed. |
| `min_distance_um` | 5.0 | Smallest distance between object centres (≈ nucleus radius). |
| `min_size_px` | 20 | Remove objects smaller than this. |
| `fill_holes` | True | Fill holes inside objects. |
| `parent` | None | Link each object to the object it overlaps most in this label set. |

## Segmentation: SAM 3 (text concept) (`segment_sam3`)

Segments every instance of a text concept ("nucleus", "spheroid") with SAM 3, plane by plane, from 1-3 channels shown as a grey or colour image. Runs in a separate SAM 3 environment (Tools → SAM 3 settings). Best for organoids, spheroids and unusual objects; use Cellpose for high-throughput cell and nucleus segmentation.

| Parameter | Default | Meaning |
|---|---|---|
| `prompt` | required | Concept to segment, e.g. "nucleus", "spheroid". |
| `channels` | required | 1-3 channels shown to SAM 3. |
| `output` | 'objects' | Name of the new label set. |
| `confidence` | 0.5 | Minimum detection score. |
| `min_size_px` | 20 | Remove objects smaller than this. |
| `parent` | None | Link objects to this label set by overlap. |
| `python` | None | Python of the SAM 3 environment; empty = from settings. |
| `checkpoint` | None | Path of sam3.pt; empty = from settings, else Hugging Face. |
| `device` | 'auto' | auto, cpu or gpu. |
